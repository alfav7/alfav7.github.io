Project Saya

Berikut adalah beberapa project yang pernah saya kerjakan

Instalasi CCTV Industri

Salah satu project yang saya kerjakan yaitu pemasangan 34 titik IP Camera di salah satu pabrik pada kawasan industri Jababeka. Fokus utama mencakup manajemen kabel yang terstruktur, konfigurasi server DVR, dan integrasi sistem keamanan secara real-time.

wifivoucher.id

Mengelola infrastruktur jaringan wifivoucher.id yang melayani lebih dari 150 klien aktif dengan fokus pada ketersediaan tinggi (High Availability).

Konfigurasi mencakup Load Balancing & Failover dual ISP dengan metode Netwatch untuk memastikan perpindahan jalur internet secara instan dan otomatis jika terjadi gangguan.

Hardware & OS Maintenance

Saya juga terbiasa melakukan pemeliharaan laptop dan PC meliputi Deep Cleaning, penggantian thermal paste, Perakitan PC serta upgrade hardware untuk optimalisasi performa workstation kantor.

Menangani juga optimasi sistem operasi melalui instalasi ulang, pembersihan file sampah, dan penanganan error sistem guna menjaga stabilitas kerja perangkat.

Install Server & Network

Pengalaman dalam instalasi dan konfigurasi unit server dari tahap perakitan fisik hingga deployment sistem. saya membangun lingkungan server yang fleksibel dengan fitur backup dan restore yang cepat.

Selain itu saya juga membuat home server sendiri dengan memanfaatkan laptop yang tidak terpakai menggunakan Proxmox, di dalam Proxmox saya menginstall TrueNas untuk local backup dan Debian 12 untuk web server.
